## 六、技能提出的规则歧义（需要你定夺）

技能在运行中**主动标记了一处清单语义歧义**，这是它比旧手写脚本严谨之处：

> **「后排不买」判据口径**：清单原文写"现价 < 同板块最强票价 × 0.99"（按**绝对股价**比），但按股价比强弱在语义上有歧义——高价股本就不等于强。
>
> - `price`（默认，清单原文）：按绝对股价
> - `pct`：按涨幅（现价涨幅 < 同板块最强涨幅）

**我的建议**：用 `pct`（按涨幅）更符合"后排=涨得弱"的本意。你觉得呢？确认后我执行：

```
run.py config set confirmations.backrow_basis=<price/pct>
```
