# 定盘实时任务 · 公式清单（v3 主线龙头低吸版）

> 任务：**A股实盘助手**（#11182153）｜每 10 分钟运行一次
> 内核：`preopen.py`（竞价）→ `watch.py`（盘中）→ `daily.py`（收盘）
> 本文把所有**判定公式与阈值**列全，方便你随时校准。

---

## 一、大盘红绿灯（决定能不能开仓）

```
MA5  = 近5日收盘均值
MA10 = 近10日收盘均值
MA20 = 近20日收盘均值
红线 = MA20 × 0.98
```

| 条件 | 灯位 | 动作 |
|---|---|---|
| 上证 ≥ MA20 | 🟢 绿灯 | 正常给买点，仓位上限 100%（单票40%）|
| MA10 ≤ 上证 < MA20 | 🟡 黄灯 | 只给强信号，仓位减半（单票20%）|
| 上证 < MA10 | 🔴 红灯 | 不给买点，只提示风险；有买点形态也记入观察 |
| 上证 < 红线（MA20×0.98）| 🔴 红灯 | 严重弱市，仓位上限 20% |

## 二、主线判定（反复最强才叫主线）

**计分制，看近 3 个交易日存档：**

```
每个交易日：
  板块涨幅进 TOP5            → +2 分
  板块涨幅 ≥ 0.8% 且 成交额 ≥ 150亿 → +1 分
3日累计：
  得分 ≥ 4  → ⭐ 主线（反复最强）
  得分 2-3  → 👁 观察（2次最强）
  得分 1    → ↻ 轮动（不做）
```

> **原则**：一天最强 = 轮动；连续/间歇反复最强 = 主线。

## 三、龙头三条件（在主线内选龙）

| 条件 | 判据 | 谁判 |
|---|---|---|
| ① 正宗 | 真有不小业务，不硬蹭 | **Agent 用业务知识判断** |
| ② 有记忆 | 60日内涨停次数 **≥ 3 次**（脚本标 ★）| 脚本自动 |
| ③ 强度最高 | 连板数最高 / 最先涨停 / 封单最猛 | 脚本按 lbc 排序 |

**"有记忆"公式**：
```
zt60 = count( 日涨幅 ≥ 9.5% )  over 近60个交易日
mem  = zt60 ≥ 3
```

## 四、趋势确认（票本身够不够格）

```
MA5今 = 近5日收盘均值    MA5昨 = 前5日收盘均值
up    = MA5今 > MA5昨  且  现价 > MA5今       ← MA5向上
zt5   = 近5日内有任一日涨幅 ≥ 9.5%            ← 近期涨停
trend = (up or zt5) 且 现价 > MA10            ← 趋势成立（硬门槛）
```

## 五、买点 = 下跌动能衰竭四件套

**先要满足回落形态：**
```
当前涨幅 -2% ≤ pct ≤ +6%        ← 温和，不追高
回落幅度 2% ≤ pullback ≤ 8%      ← 冲高后确实回调了
pullback = (当日最高 - 现价) / 当日最高 × 100
```

**再要四件套齐全（A级）：**

| # | 信号 | 公式 | 含义 |
|---|---|---|---|
| ① | 缩量 | 回落段均量 ≤ 冲高段均量 × **0.85** | 抛压衰竭 |
| ② | 不再创新低 | 最低点出现后 **≥10 分钟**未破 | 止跌 |
| ③ | 分时承接 | 现价 > 3分钟前价 **且** 近3分钟量 > 前3分钟量 × **1.1** | 新买盘介入 |
| ④ | 板块回流 | 同板块内 ≥1 只票"近3分钟回升" | 龙头先企稳 |

```
A级 = 四件套全齐
B级 = 形态+位置达标，四件套不齐
```

**买入位置要求（二选一）：**
```
|现价/昨收 - 1| × 100 ≤ 1.5%      ← 回到昨收 ±1.5%（正负0附近）
或 现价 ≥ 分时均价(VWAP)          ← 站回均价线
VWAP = 累计成交额 / (累计成交量 × 100)
```

## 六、三不买（自动拦截 🚫）

| 拦截 | 公式 |
|---|---|
| **首阴不买** | 昨日涨幅 ≥ 9.5% **且** 现价 < 昨收 × 0.99 |
| **破位不买** | 现价 < MA10 |
| **后排不买** | 现价 < 同板块最强票价 × 0.99 |

## 七、卖点 / 风控铁律

```
浮盈亏 = (现价 / 成本 - 1) × 100
```

| 触发 | 输出 | 动作 |
|---|---|---|
| 现价 ≤ 自设止损价 | 🔴 卖出 | 破自设止损 |
| 浮盈亏 ≤ **-5%** | ⛔ 强制止损 | **无条件离场** |
| 浮盈亏 ≤ -3% | ⚠️ 止损预警 | 看卖压，破位即走 |
| 浮盈亏 ≤ -2% 且 大盘非绿灯 | ⚠️ 减仓提示 | 先减半仓 |
| 现价 ≥ 目标价 | 🟢 止盈 | 达目标 |

## 八、仓位（凯利 40%）

```
绿灯：单票 = 总资金 40%
黄灯：单票 = 总资金 20%
红灯：不开仓
买入后不补仓、不摊平
止损价 = min(当日最低, 现价 × 0.95)
```

**昨日涨停延续度**（判情绪退潮）：
```
今日竞价 ≥ +2%   → ✓ 主线延续
-1% ~ +2%        → △ 分歧
< -1%            → ✗ 退潮预警
```
